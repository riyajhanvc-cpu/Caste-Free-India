# Caste-Free-India
🇮🇳 **CASTE FREE INDIA** 🇮🇳  **जाति से नहीं, इंसानियत से पहचान। ❤️**  हमारा उद्देश्य किसी व्यक्ति, समुदाय या धर्म के खिलाफ होना नहीं है। हमारा उद्देश्य उस सोच के खिलाफ आवाज़ उठाना है, जो इंसानों को जाति के आधार पर बाँटती है।  हम मानते हैं कि किसी इंसान की पहचान उसकी जाति से नहीं, बल्कि उसके **कर्म, चरित्र और इंसानियत** से होनी चाहिए
